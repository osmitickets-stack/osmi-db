- `trg_update_api_calls`: Actualiza updated_at en api_calls

**Observaciones:**
- Webhooks con `secret_token` para firma HMAC
- `signature_header` para verificar integridad
- API calls con request/response completos (JSONB)
- Métricas de rendimiento: `response_time_ms`
- Control de reintentos: `retry_count`
- CHECK para métodos HTTP válidos


📋 Tablas auditadas del schema integration:
✅ integration.webhooks

    12 columnas

    PK: id

    UNIQUE: public_uuid

    Campos: provider, event_type, target_url

    Seguridad: secret_token, signature_header

    Control: is_active, last_triggered_at

    Configuración flexible: config (JSONB)

✅ integration.api_calls

    15 columnas

    PK: id

    FK: user_id → auth.users(id)

    CHECK: method IN (GET, POST, PUT, DELETE, PATCH)

    Request/Response completos: request_body, request_headers, response_body, response_headers

    Métricas: response_time_ms, retry_count

    Estado: success, error_message
