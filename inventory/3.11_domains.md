### DDL de cada dominio

#### Schema: `global`

```sql
-- email_address
CREATE DOMAIN global.email_address AS VARCHAR(320)
CHECK (VALUE ~ '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$');

-- phone_number
CREATE DOMAIN global.phone_number AS VARCHAR(20)
CHECK (
    VALUE ~ '^\+[1-9][0-9]{1,14}$' OR 
    VALUE ~ '^[0-9]{8,15}$'
);

-- currency_code
CREATE DOMAIN global.currency_code AS VARCHAR(3)
CHECK (VALUE ~ '^[A-Z]{3}$');

-- percentage
CREATE DOMAIN global.percentage AS NUMERIC(5,4)
CHECK (VALUE >= 0 AND VALUE <= 1);

-- country_code
CREATE DOMAIN global.country_code AS VARCHAR(2)
CHECK (VALUE ~ '^[A-Z]{2}$');

-- timezone_name
CREATE DOMAIN global.timezone_name AS VARCHAR(50)
CHECK (
    VALUE ~ '^[A-Za-z_]+/[A-Za-z_]+$' OR 
    VALUE = 'UTC'
);
```

#### Schema: `ticketing`

```sql
-- event_status
CREATE DOMAIN ticketing.event_status AS VARCHAR(20)
CHECK (VALUE IN (
    'draft', 'scheduled', 'published', 'live', 
    'cancelled', 'completed', 'sold_out', 'archived'
));

-- ticket_status
CREATE DOMAIN ticketing.ticket_status AS VARCHAR(20)
CHECK (VALUE IN (
    'available', 'reserved', 'sold', 'checked_in', 
    'cancelled', 'refunded', 'expired'
));
```

#### Schema: `billing`

```sql
-- payment_status
CREATE DOMAIN billing.payment_status AS VARCHAR(20)
CHECK (VALUE IN (
    'pending', 'processing', 'completed', 'failed', 
    'refunded', 'disputed', 'chargeback', 'expired'
));
```

### Observaciones importantes

1. **Todos los dominios tienen `NOT NULL = false`**, lo que significa que permiten valores nulos a menos que la columna lo impida explícitamente.

2. **Los dominios están correctamente definidos** con validaciones robustas:
   - `email_address`: Regex completo para email
   - `phone_number`: Soporte para internacional (+XX) y local
   - `currency_code`: Código ISO 4217 (3 letras mayúsculas)
   - `country_code`: Código ISO 3166 (2 letras mayúsculas)
   - `percentage`: Rango 0-1 con 4 decimales

3. **Los estados usan valores en minúsculas**, consistente con las definiciones.

4. **Los dominios están en el schema correcto** según la responsabilidad de cada módulo.
